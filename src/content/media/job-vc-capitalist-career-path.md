## 投資する人か、投資される会社を支える人か

ベンチャーキャピタリストは、未上場のスタートアップに出資し、その成長を支える職種です。投資して終わりではなく、出資後に経営の相談に乗り、次の資金調達や上場を見据えて動きます。

ただし、会社によって役割の重心が違います。案件を探して投資判断まで担う立場と、投資後の支援を専門にする立場があります。ファンドの規模や体制によって、この分業の形が変わります。

この記事では、入社後の進み方、数年後の分岐、そして次に進むときの選択肢を整理します。本記事の内容は2026年8月時点の公開情報にもとづきます。最新の募集要項は各社公式サイトをご確認ください。

## 仕事の流れと、時間の使い方

| 工程 | 主な作業 | 難しさ |
|---|---|---|
| ソーシング | 投資先候補を探す。起業家と会う | 良い案件が回ってくる立場を作る |
| 初期検討 | 事業の内容と市場を調べる | 短時間で見極める |
| 精査 | 財務、契約、技術、人を確認する | 何を確認しないと危険かの判断 |
| 投資判断 | 社内の投資委員会に諮る | 反対されたときの説得 |
| 条件交渉 | 出資比率、権利、取締役の派遣 | 起業家との関係を保ちながら詰める |
| 投資後の支援 | 採用、次の調達、事業の相談 | 口を出しすぎない距離感 |
| 回収 | 上場、売却、償却 | 損切りの判断 |

**時間の大半はソーシングと初期検討に使われます。** 実際に投資に至る案件は、検討した数のごく一部です。何十社と会って1社という状態が続きます。

この構造が、この職種の適性を分けます。成果が出ない期間が長く、しかも投資した結果が分かるのは数年後です。短い周期で手応えを得たい方には向きません。

## 入社後の進み方と、分岐の時期

| 時期 | 主な状態 | この時期の分岐 |
|---|---|---|
| 入社〜1年 | 案件の調査を担当する。先輩に同行する | 業界の見方を掴めるか |
| 1〜3年 | 自分で案件を持ち込む。精査を主導する | 起業家から相談される立場になるか |
| 3〜5年 | 投資判断に関与する。担当先を持つ | 自分の判断で投資を通せるか |
| 5年以降 | 投資委員会の一員、またはファンドの運営 | 投資に集中するか、ファンド側に回るか |

厚生労働省の職業情報提供サイト（job tag）では、ファンドマネージャーについて、アナリスト職から段階的にキャリアを形成し、実務経験は3〜5年が一般的、シニアレベルは10年以上の経験が必要とされています。ベンチャーキャピタルでも、投資判断を任されるまでに相応の年数がかかります。

最大の関門は3〜5年目です。自分が推した案件を、社内で通せるかどうか。ここを越えないと、調査を担当する立場に留まります。

## ファンドの制度的な枠組みが、仕事を規定する

この職種を理解するうえで、ファンドがどういう制度のもとで運営されているかを知っておくと役に立ちます。

金融庁の説明によれば、**1人以上の適格機関投資家かつ49人以下の投資判断能力を有すると見込まれる一定の者等を相手とする私募** に該当する場合、届出により参入することが可能とされています。これが適格機関投資家等特例業務です。届出先は、本店などを管轄する財務局等とされています。

一方、出資者に投資判断能力を有すると見込まれる一定の者以外の者が含まれる場合には、投資運用業の登録が必要になるとされています。届出制と登録制では、規制の水準が異なります。

**実務上の意味** — 出資者を49人以下に絞る枠組みで運営されるファンドが多いということは、**誰から資金を集めるかがファンドの性格を決める** ということです。事業会社が主な出資者であれば、その会社の事業と関係する領域への投資が期待されます。金融機関が中心であれば、回収の確実性が重視されます。

転職の際に確認しておく価値があるのは、そのファンドの出資者の構成です。投資の方針も、意思決定のスピードも、ここに規定されます。求人票には書かれませんが、面接で聞けば答えてもらえることが多くあります。

## 投資判断を担う道

案件を見つけ、判断し、責任を負う方向です。

**評価される要素**

- 良い案件が自分のところに来る状態を作れる
- 短時間で見極め、深く調べるべき点を特定できる
- 反対されても通すべき案件を、社内で通せる

**在籍中に積むべきもの**

1. **自分が推して投資した案件** — 誰の判断だったかが明確なもの
2. **推さなかった案件と、その後** — 見送った会社が伸びた場合の振り返り
3. **損切りの判断** — 追加投資をしない、償却するという決定

3つ目を語れる方は多くありません。投資した会社が計画どおりに進まないことは頻繁に起こります。そこでどう判断したかに、実力が表れます。

## 投資後の支援に軸足を置く道

出資先の成長を支えることを専門にする方向です。採用の支援、次の資金調達の設計、事業提携の紹介、経営陣の補強。

この道では、投資の目利きより、事業を動かす力が問われます。事業会社での経験を持つ方が、この領域で評価されることがあります。

**この経験は外にも通じます** — 支援先の経営に深く関わった経験は、事業会社の経営幹部への道につながります。[CxO候補・経営幹部のキャリアパス](/media/job-cxo-kouho-career-path/)をご覧ください。

## ファンド側・外に出る道

**ファンドの運営側へ** — 資金を集める側に回ります。出資者との関係構築、ファンドの設計、報告と説明。投資とは別の専門性が要ります。

**事業会社の経営側へ** — 支援先や他社の経営に入る道です。投資家として外から見ていた立場から、当事者になります。

**独立して自分のファンドを作る** — 実績と、資金を集められる関係が前提になります。年数がかかる道です。

**M&Aや財務の領域へ** — [M&Aアドバイザーのキャリアパス](/media/ma-advisor-career-path/)、[会計・財務コンサルタントのキャリアパス](/media/fas-consultant-career-path/)が隣接します。

この職種で最も多い転職の失敗は、成果が確定するまでの時間を見誤ることです。投資した会社がどうなるかは、5年から10年かけて分かります。その間、自分の判断が正しかったのかは分からないまま働きます。事業会社で四半期ごとに数字を見てきた方が移ると、この不確かさに戸惑うことがあります。入社前に考えていただきたいのは、成果が分からない状態で自分の判断を続けられるかという点です。あわせて確認しておきたいのが、ファンドの残存期間です。設立から年数が経ったファンドでは、新規投資より回収が中心になります。新しい案件に関わりたい方が、回収期のファンドに入ると、想定と違うことになります。

job tag に掲載されているファンドマネージャーの数値は、次のとおりです。

| 項目 | 数値 |
|---|---|
| 年収 | 1,134.6万円 |
| 求人賃金（月額） | 28.3万円 |
| 平均年齢 | 39.4歳 |
| 月間労働時間 | 162時間 |
| 時間当たり賃金 | 5,497円 |
| 有効求人倍率 | 0.57 |
| 就業者数 | 82,920人 |

年収・平均年齢・労働時間・時間当たり賃金は令和7年賃金構造基本統計調査、求人賃金と有効求人倍率は令和6年度、就業者数は令和2年国勢調査の数値です。

**年収1,134.6万円は、ここまで見てきた職種のなかで最も高い水準です。** 一方、就業者数82,920人という規模は小さく、有効求人倍率0.57は1を下回ります。

高い水準の一方で、入口が狭い。この構造が、この職種の転職難易度を規定しています。詳しくは[ベンチャーキャピタリストの転職難易度](/media/job-vc-capitalist-tenshoku-nanido/)で整理しています。

## まとめ

ベンチャーキャピタリストのキャリアパスについて、押さえるべき点を整理します。

- 時間の大半はソーシングと初期検討。投資に至るのは検討数のごく一部
- 成果が確定するまで5年から10年かかる。不確かさに耐えられるかが適性を分ける
- 投資判断を任されるまでに3〜5年、シニアには10年以上の経験が必要とされる
- ファンドの出資者の構成が、投資方針と意思決定の速さを規定する
- 年収1,134.6万円は最も高い水準だが、就業者82,920人と市場は小さい
- ファンドの残存期間によって、新規投資が中心か回収が中心かが変わる

本記事の内容は2026年8月時点の公開情報にもとづきます。統計の数値は調査区分全体のものであり、この職種そのものを示すものではありません。制度の適用については個別の事情により判断が変わりますので、専門家にご確認ください。

## よくある質問

**Q. 金融の経験がないとベンチャーキャピタリストになれませんか。**

A. 事業会社出身の方が投資後の支援を担う形で入る例があります。ただし、投資判断まで担うには財務や契約の理解が要ります。どちらの役割を目指すかで、必要な経験が変わります。

**Q. 投資した会社が失敗したら、評価はどうなりますか。**

A. すべての投資が成功することは想定されていません。見るべきは、判断の過程が妥当だったかと、うまくいかないと分かった時点でどう動いたかです。損切りの判断ができるかも評価の対象になります。

**Q. ファンドの出資者は、なぜ確認する必要があるのですか。**

A. 投資の方針と意思決定の速さが、出資者の性格に規定されるためです。事業会社が中心なら関連領域への投資が期待され、金融機関が中心なら回収の確実性が重視されます。面接で聞けば答えてもらえることが多くあります。
