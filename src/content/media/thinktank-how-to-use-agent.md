シンクタンク研究員の転職市場は、一般的なビジネスパーソンとは異なる特有の構造を持っている。求人数が絶対的に少なく、多くのポジションが表に出る前に内定まで進む。公開求人だけを追う転職活動では、選択肢の大半を見逃す可能性が高い。

転職エージェントを活用すべき理由は「サポートを受けられるから」という表面的な話ではなく、この市場構造そのものにある。本稿では、シンクタンク研究員という職種に固有の転職市場の特性を整理したうえで、エージェント活用の実務的な意義と、適切なエージェントの選び方を解説する。

## シンクタンク研究員の転職市場に固有の構造

### 求人の絶対数が少なく、非公開比率が高い

シンクタンクや政策系組織、コンサルティングファームの研究部門は、採用枠が年間で数名から十数名規模にとどまることが多い。さらに、これらのポジションの多くは「欠員補充型」ではなく、「特定テーマの研究強化」や「プロジェクト受注に伴う即戦力確保」といった背景で発生する。そのため、組織側は採用ニーズが生じた時点でエージェントに打診し、適切な候補者がいれば速やかに選考を進める動き方をとりやすい。

結果として、転職サイトに掲載される前に候補者が決まるケースが一定数存在する。研究員として専門性の高いキャリアを積んできた人材ほど、「待ちの転職活動」では機会を逃しやすい構造になっている。

### 専門性の言語化が評価に直結する

研究員のキャリアには、論文・報告書の執筆実績、政策提言への関与度、外部機関との連携経験など、一般的な職務経歴書の枠組みでは伝わりにくい要素が多い。採用担当者が研究職の文脈を熟知していなければ、優れた専門性を持つ候補者であっても書類選考を通過しにくくなる。

エージェントが担う「職務経歴書の言語変換」の役割は、この文脈では特に重要性が増す。

### 転職先の類型が広く、選択の軸設定が難しい

シンクタンク研究員の転職先は、同業他社にとどまらず、コンサルティングファーム、事業会社の政策・渉外部門、官公庁・独立行政法人、国際機関、スタートアップのリサーチ部門など多岐にわたる。それぞれで評価される専門性の切り出し方、求められるアウトプットの性質、年収水準が異なるため、自分のキャリア資産をどの方向に展開するかの軸設定が難しい。

市場全体を俯瞰した情報提供は、エージェントが持つ機能のなかで最も活用価値が高い部分のひとつである。

## エージェントを活用すべき具体的な理由

### 非公開求人へのアクセス

前述の構造上、非公開求人へのアクセスは実質的にエージェント経由でしか得られない場合が多い。特に、シンクタンクの上位職、財団・国際機関の専門職ポジション、コンサルティングファームのポリシー系プラクティスのシニアロールなどは、公募よりも紹介経路での採用が主流になりやすい。

### 選考過程における情報の非対称性の解消

研究員が転職活動で直面しやすい課題のひとつが、選考先組織の内部情報の少なさである。研究部門の規模、テーマの方向性、プロジェクトの受注構造、評価体系といった情報は、公開情報からは得にくい。エージェントは企業側との継続的な関係のなかでこうした情報を蓄積しており、選考準備の質を高めるうえで有用な情報源となりえる。

### 年収交渉における第三者効果

年収交渉を候補者本人が直接行うと、関係構築の初期段階で緊張感が生じやすい。エージェントを介することで、候補者は希望条件を直接提示するリスクを回避しつつ、市場相場に基づいた交渉を進めやすくなる。研究員のポジションは職務の定義が個別性を持ちやすく、オファー条件にも幅が出やすいため、この機能は特に意味を持つ。

## 年収の目安と転職先別の傾向

職種・移行先別の年収レンジはあくまで目安であり、経験年数・専門分野・組織規模によって変動幅が大きい。以下の表は一般的な傾向を整理したものである。

| 転職先の類型 | 年収レンジの目安（万円） | 特徴的な評価軸 |
|---|---|---|
| 大手シンクタンク（研究員） | 600〜1,000程度 | 研究実績・専門領域の希少性 |
| 戦略・政策系コンサルティング | 800〜1,400程度 | プロジェクト遂行力・クライアント対応 |
| 事業会社（政策・渉外・経営企画） | 700〜1,200程度 | 事業文脈への翻訳力・提言能力 |
| 官公庁・独立行政法人 | 600〜900程度 | 行政実務との親和性・安定性 |
| 国際機関・財団 | ポジションにより大きく異なる | 語学力・国際経験・専門分野の合致 |

同じ研究員経験者でも、どのスキルセットを前面に出すかによって、打診可能な求人層が変わる。エージェントとの対話のなかでこの「見せ方の設計」を行うことが、選択肢を広げるうえで有効に機能しやすい。

## ケーススタディ：政策系シンクタンクから戦略コンサルへの転身

ここでは実際の転職で見られる典型的な状況の型を整理する。

**背景の型**：国内政策系シンクタンクで5〜8年程度のキャリアを積み、産業政策・規制分野のレポート執筆や官公庁向け調査受託を主業務としてきた研究員。論文実績はあるが、民間コンサルへの転職は「ビジネス経験の乏しさ」を理由に自己評価を下げやすい。

**エージェント活用による変化**：コンサルティングファームの政策プラクティスやパブリックセクター向けチームは、官公庁との関係性・制度読解力・報告書制作の質を高く評価する傾向がある。エージェントがこの評価軸を候補者に伝え、職務経歴書を「研究実績の羅列」から「政策課題に対する問題設定から提言までの構造的な関与」として再整理することで、書類通過率が改善するケースが見られる。

**選考準備での活用**：ファームによってケース面接の比重・政策知識への期待水準が異なる。エージェントが保有する選考フィードバック情報を参照することで、準備の方向性を絞り込みやすくなる。

このケースが示すのは、エージェントの価値が「求人紹介」にとどまらず、「候補者自身が見えていない市場評価軸の可視化」にある点である。

## エージェントの選び方：研究員キャリアに適した基準

### 専門性の確認：担当者のバックグラウンドと取引先の質

エージェントを選ぶ際に最初に確認すべきは、担当者がシンクタンク・政策系・コンサルティング領域の転職支援実績を持っているかどうかである。研究員の職務内容や評価軸を理解していない担当者に支援を依頼すると、職務経歴書の言語化が表面的になり、マッチング精度が下がりやすい。

面談時に「過去にどのような研究員・アナリスト系の候補者を支援してきたか」「主要な取引先にシンクタンクや政策コンサルは含まれるか」を確認することが、担当者の専門性を見極める実務的な方法となる。

### 取り扱い求人の構成

エージェントを選ぶもうひとつの基準は、保有求人のポートフォリオである。公開求人と非公開求人のバランス、シニアポジションの有無、転職先類型の多様性（シンクタンク・コンサル・事業会社・公共セクターを横断的にカバーしているか）を確認する。

単一業界・単一層の求人に偏るエージェントでは、研究員のキャリアの幅広い展開可能性を活かした提案が受けにくくなる傾向がある。

### 複数エージェントの並行活用

シンクタンク・政策系領域に強いエージェントと、コンサルティングやハイクラス転職全般に強いエージェントを並行して利用することが、選択肢の最大化という点で合理的な場合が多い。ただし、同一求人への重複応募は選考過程での混乱を招くリスクがあるため、担当者間での情報共有ルールをあらかじめ確認しておくことが望ましい。

| 選択基準 | 確認のポイント |
|---|---|
| 担当者の専門性 | 研究員・政策系・コンサルの支援実績があるか |
| 求人の多様性 | シンクタンク・コンサル・事業会社・公共セクターを横断しているか |
| 非公開求人の厚み | 公開求人にない上位・専門職ポジションを保有しているか |
| 情報提供の質 | 選考フィードバック・組織内部情報の精度はどの程度か |
| 対応スタンス | 希望を一方的に誘導せず、候補者の軸を整理する対話ができるか |

## よくある質問

**Q. 転職エージェントへの登録は転職意思が固まってからでないといけませんか？**

そうした制約はありません。「まず市場感を知りたい」「自分のキャリアがどう評価されるか確認したい」という段階での利用も実務上は一般的です。ただし、担当者への希望軸の開示が曖昧なまま進めると、マッチング精度が下がりやすいため、現時点での考えの整理を面談前に行っておくことは有効です。

**Q. 研究員として学術系への転職を検討していますが、エージェントは有効ですか？**

大学・研究機関のポジションについては、エージェント経由の採用よりも公募や学術ネットワーク経由が主流であるため、エージェントが提供できる価値は限定的になりやすい傾向があります。一方で、民間シンクタンクや政策系コンサル・国際機関への展開を並行して検討している場合は、エージェントの活用が有効に機能しやすくなります。

**Q. 在職中の転職活動はエージェントを通じた方が進めやすいですか？**

在職中は時間的な制約が大きいため、求人のスクリーニング・日程調整・情報収集をエージェントに委ねることで効率を高めやすい面があります。特に、複数社を並行して進める場合の全体スケジュール管理は、エージェントのサポートが実質的に役立つ場面です。

**Q. 年収が下がる可能性がある転職の場合、エージェントに相談しにくいですか？**

そのような懸念は必要ありません。年収維持・向上を前提とした提案がエージェントの基本スタンスではありますが、ワークスタイルの変化・専門性の深化・社会的影響力の追求を優先する転職方針であれば、その軸を共有することで適切な求人提案を受けやすくなります。
