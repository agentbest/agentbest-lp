## 報酬を決めるのは分析力ではなく、関与する意思決定の重さ

前提として押さえておきたいのは、この職種の報酬が扱う手法の高度さでは決まらない点です。

同じ分析業務でも、依頼された内容を実装する立場と、そもそも何を分析すべきかを顧客と決める立場では、求められる経験が違います。前者は工程が明確に区切られ、後者は経営判断に近い領域まで踏み込みます。求人票のレンジ幅が広いのは、この両方を同じ職種名で束ねているためです。

したがって、年収を比較する際に手法のスキルセットで並べてもあまり意味がありません。見るべきは、どの粒度の意思決定に関与するポジションかです。

## 統計上の平均年収が低く見えるのはなぜか

職種全体の水準は、厚生労働省が運営する職業情報提供サイト job tag で確認できます。データサイエンティストと、近接するITコンサルタントの数値を並べます。

| 項目 | データサイエンティスト | ITコンサルタント |
|---|---|---|
| 平均年収 | 611.9万円 | 889万円 |
| 平均年齢 | 43.9歳 | 38.3歳 |
| 月間労働時間 | 159時間 | 173時間 |
| 時間給（一般労働者） | 3,000円 | 4,026円 |
| 就業者数 | 79,260人 | 656,770人 |
| 求人賃金（月額） | 30.3万円 | 35.4万円 |
| 有効求人倍率 | 11.88 | 0.89 |

平均年収・平均年齢・月間労働時間・時間給は令和7年賃金構造基本統計調査、就業者数は令和2年国勢調査、求人賃金と有効求人倍率は令和6年度ハローワーク求人統計にもとづく数値です。

まず目を引くのが、データサイエンティストの平均年収611.9万円が、ITコンサルタントの889万円を大きく下回っている点です。データ人材は高給というイメージと食い違います。

理由のひとつは、就業者数の差にあります。データサイエンティストは79,260人、ITコンサルタントは656,770人で、母集団の性質が異なります。前者は職種として集計され始めた時期が新しく、統計上の分類も別です。年収の水準だけを取り出して優劣を語るのは適切ではありません。

もうひとつ注意が要るのが、平均年収611.9万円と求人賃金30.3万円の落差です。求人賃金を単純に12倍すると363.6万円で、平均年収の6割程度にとどまります。これは矛盾ではなく母集団が違います。前者は賃金構造基本統計調査における当該分類の全体平均であり、後者はハローワークに出ている求人の提示額です。コンサルティングファームや分析専門企業の中途採用がハローワーク経由で行われることは多くないため、後者を相場として読むのは適切ではありません。

平均年齢43.9歳という点も見落とせません。この数値は近接職種と比べても高く、20代でこの水準に届くという意味ではありません。

## 分析を主業とする上場企業が開示している実額

より実態に近い数値は、上場企業の有価証券報告書から取れます。データ分析を主業とする企業の例として、株式会社ブレインパッドの記載を示します。

| 項目 | 内容 |
|---|---|
| 対象事業年度 | 2025年6月期 |
| 提出会社の従業員数 | 564人〔18〕 |
| 平均年齢 | 35.2歳 |
| 平均勤続年数 | 4年1ヶ月 |
| 平均年間給与 | 7,610千円 |

〔　〕内は臨時雇用者数（派遣社員、パートタイマー）の年間平均人員で、外数として記載されているものです。

ここで一点、比較の際に注意したい記載があります。同社の有価証券報告書では、平均年間給与について「基準外賃金を含んでおります」と注記されています。他の多くの企業が「賞与及び基準外賃金を含む」と記載しているのと、文言が異なります。複数社の数値を横に並べる際は、この注記の違いを確認する必要があります。

数値そのものを見ると、平均年齢35.2歳で平均年間給与7,610千円です。job tag のデータサイエンティストの平均年収611.9万円（平均年齢43.9歳）と比べると、より若い年齢構成でより高い水準にあります。

同社の連結従業員数は589人〔18〕で、セグメント別ではプロフェッショナルサービス事業が299人〔3〕、プロダクト事業が120人〔2〕、全社（共通）が170人〔13〕です。前連結会計年度末に比べ44名増加した理由として、事業規模の拡大に伴う新規採用が挙げられています。採用による増加は平均勤続年数と平均給与を押し下げる方向に働くため、この数値もその影響を受けている可能性があります。

## 報酬を押し上げる5つの要素

この職種で報酬が動く要因は、いくつかに整理できます。

**関与する意思決定の粒度。** 依頼された分析を実装する立場か、課題設定から関与する立場かで評価が変わります。これが最も直接的に効く要素です。

**扱うデータの規模と種類。** 行数の桁、データソースの数、リアルタイム性の有無などが、経験の水準を示します。

**業界知見。** 金融、製造、小売など、特定領域の業務理解を持つ人材は母集団が小さくなります。データの意味を業務の文脈で解釈できることが、分析の質に直結するためです。

**実装まで担えるか。** 分析結果を業務システムに組み込む工程まで関与できる人材は限られます。job tag でも、この職務の流れに実装が含まれることが示されています。

**入社時の職位。** 多くのファームで等級制度が設けられ、レンジは職位に紐づきます。入社後の昇給より、入社時の等級の影響が大きくなる傾向があります。

この5つのうち、転職の前後で最も動かしやすいのは業界知見の見せ方です。前職で扱っていた業務の理解は、すでに手元にあります。それを分析の文脈で説明できる形に整えるだけで、評価の入り口が変わります。逆に、手法の習得は時間がかかるうえ、報酬への効き方も間接的です。優先順位を誤ると、準備に使った期間の割に提示額が動きません。

## オファーは内訳をそろえて比べる

オファーの段階で整理しておきたい点を挙げます。

固定給と賞与の内訳は最初に確認したい項目です。前述のとおり、開示資料の平均年間給与も企業によって含まれる範囲の記載が異なります。提示額と比較する際は、内訳を揃えて見る必要があります。

配属予定の事業も確認しておきます。受託の分析事業か、自社プロダクト事業かで、評価の指標が変わる場合があります。

等級の運用も見ておきます。次の等級に上がる要件が明文化されているかどうかで、数年後の見通しが変わります。データサイエンティスト協会が示すスキル区分のように、社内でも段階が定義されている会社があります。

稼働時間の前提も確認しておきたい項目です。前掲の職種統計では月間労働時間が159時間と示されており、近接するITコンサルタントの173時間より短くなっています。ただしこれは当該分類全体の平均であり、案件の局面によって変動します。時間あたりで見た水準を把握しておくと、提示額の評価がしやすくなります。

複数社から提示を受けている場合は、金額だけでなく、配属事業と等級要件をそろえて比較します。この職種は関与する意思決定の粒度で報酬が動くため、初年度の金額が低いほうが数年後に上回るという逆転が起こり得ます。

## まとめ

データコンサルタントの年収は、扱う手法の高度さでは決まりません。官公庁統計ではデータサイエンティストの平均年収が611.9万円、平均年齢が43.9歳と示されており、ITコンサルタントの889万円を下回ります。ただし就業者数が79,260人と656,770人で母集団の性質が異なり、単純な優劣の比較にはなりません。

上場企業の開示では、データ分析を主業とする企業の平均年間給与が7,610千円、平均年齢35.2歳という水準が確認できます。統計の平均値より若い年齢構成で高い水準にあり、どの母集団に属するかで実態が変わることが読み取れます。

自分の場合いくらになるかは、関与する意思決定の粒度と、扱うデータの規模で決まる部分が大きくなります。公開されている平均値は構造の理解に使い、提示額は個別に確認することをおすすめします。

## よくある質問

**Q. データコンサルタントの平均年収はいくらですか。**

この職種単独の公的統計はありません。近接する職種として、職業情報提供サイト job tag の「データサイエンティスト」の平均年収が611.9万円（令和7年賃金構造基本統計調査）と示されています。ただし平均年齢43.9歳の集団の平均値であり、そのまま個人の想定額にはなりません。

**Q. なぜデータ職の平均年収がITコンサルタントより低いのですか。**

母集団が異なるためです。データサイエンティストの就業者数は79,260人、ITコンサルタントは656,770人で、統計上の分類も別です。前者には事業会社でデータ集計を担う層も広く含まれます。職種間の優劣を示す数値ではありません。

**Q. 事業会社のデータ組織と比べてどちらが高いですか。**

一律には言えません。支援側は担当する案件の規模と職位でレンジが動き、事業会社側は社内の等級制度に紐づく傾向があります。比較する場合は、提示額の内訳と昇給の運用まで含めて見る必要があります。
