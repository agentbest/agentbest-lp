# M&Aニュース（/media/ma-news/）

上場企業の**適時開示（TDnet）**からM&A案件を拾って、`src/content/news/*.md` を自動生成する。
コトラの「M&A業界ニュース」と同じ位置づけ——毎日更新して検索流入を溜め、記事下のCTAでM&A転職の相談につなげる面。

## 動かし方

```bash
node tools/ma-news/run.mjs              # 直近2日分
node tools/ma-news/run.mjs --days 7     # 直近7日分
node tools/ma-news/run.mjs --date 20260820
node tools/ma-news/run.mjs --dry        # 書き込まずに結果だけ見る
```

必要なもの：Node 18以上と `pdftotext`（Git for Windows に同梱。Ubuntuなら `poppler-utils`）。

無人運用は `.github/workflows/ma-news.yml`。毎朝7時すぎ（JST）に走り、
新しい記事があればコミット→push→Vercelが自動デプロイ、まで一本でつながっている。

## 中で何をしているか

| ファイル | 役割 |
| --- | --- |
| `classify.mjs` | 開示タイトルから「M&Aニュースとして出すか」を判定。1日200〜400件の開示から数件に絞る |
| `pdf.mjs` | 開示PDFを取得し `pdftotext` でテキスト化（`cache/` に保存） |
| `parse.mjs` | 正規化・セクション分割・金額・日付の共通処理 |
| `fields.mjs` | 「(1)名称 (2)所在地 …」の会社概要テーブルから値を取り出す |
| `extract.mjs` | 1件の開示 → 事実だけの構造体。`gate()` が記事にしてよいかを判定 |
| `render.mjs` | 事実からMarkdownを組み立てる |
| `run.mjs` | 日次実行の入口。既にあるファイルは触らないので何度流しても増えない |

## 決めごと

- **開示文の文章は写さない。** 記事の文は `render.mjs` の型から作り、開示からは固有名詞・数値・日付だけを取る。
- **単位が読めない数値は捨てる。** 千円の表を百万円と読むと桁が1000倍ずれる。推測はしない。
- **中途半端なら出さない。** 対象会社名が取れない、事実が2つ未満、といったものは `gate()` で見送る。
  見送った理由は `log/*.json` に残るので、取りこぼしが多いと感じたらそこを見る。
- **公開買付（TOB）は今のところ対象外。** 開示の様式が別（買付価格・応募期間が主）で、
  同じ型で書くと事実を取り違える。足すなら専用のテンプレートを用意すること。

## 精度を上げたいとき

`log/*.json` の `skippedItems` に「なぜ落としたか」が入っている。
`対象会社名が取れない` が多い形式を1つ選び、`fields.mjs` の拾い方を足すのが一番効く。
変更したら必ず `--dry` で数日分を流し、**見出しと本文が事実と合っているか**を目視すること。
ここは自動で回る場所なので、間違いもそのまま自動で公開される。
